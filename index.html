    ORG1 format

    Format details used by this encryption page.

    • AES-256-GCMAuthenticated encryption
    • PBKDF2-SHA-256600,000 rounds
    • 16-byte saltRandom per message
    • 12-byte IVRandom per message

    Output: ORG1:salt:iv:ciphertext. The ciphertext includes the 16-byte GCM authentication tag. Keep your passphrase safe; it cannot be recovered.

    Format, security and compatibility notes

    ORG1 derives a 256-bit key with PBKDF2-HMAC-SHA-256 using 600,000 iterations, a random 16-byte salt and a random 12-byte AES-GCM IV. Output uses four colon-separated fields with base64url-encoded binary values.

    The passphrase used for each encrypted record is separate from the organization access password. Do not use a short shared access password as an encryption passphrase. A lost encryption passphrase means the encrypted text cannot be recovered.

    ORG1's iteration count and field layout are fixed for compatibility. Any change requires a new format version.
